About this demo. The full ResilienceOS platform runs 5 real microservices plus a control plane, chaos agent, Prometheus and Grafana from docker-compose up (8 GB RAM), with 53 integration tests covering the same five fault types and three named scenarios you can trigger here. This console simulates that behavior in the browser: a dependency graph with circuit breakers, fault propagation rules and blast-radius measurement, driving the same topology view and post-mortem structure (what broke, why, blast radius, timeline). In the full stack the post-mortem is written by the Claude API from the recorded event stream; here it is generated from simulation state so it runs with no keys. Experiment surface, scenarios, post-mortem spec and acceptance tests by Keshvi Pipwala; implementation AI-assisted.
